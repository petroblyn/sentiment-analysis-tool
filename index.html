    Technical explanation

    Approach. This is a lexicon-based (rule-based) classifier, the same family as VADER. Each word in a built-in dictionary carries a weight from −3 (very negative) to +3 (very positive).

    1. Tokenize: lowercase the text, strip punctuation, split into words.
    2. Score words: look up each word in the lexicon.
    3. Handle context: a negator (not, never, no) within the previous 3 words flips the sign and softens it (×−0.8). An intensifier (very, extremely) multiplies by 1.5; a dampener (slightly) by 0.6. Exclamation marks add a small boost.
    4. Normalize: sum the scores s and squash to a −1…+1 compound score with s / √(s² + 15).
    5. Classify: compound ≥ 0.15 is Positive, ≤ −0.15 is Negative, otherwise Neutral.
    6. Tag topics: keyword groups (price, support, delivery, quality, app) link each comment to a topic so average sentiment can be compared.

    Machine learning link. This is text classification with hand-set features. A learned model (Naive Bayes, logistic regression on TF-IDF, or a transformer) would instead learn the word weights from labelled data. The lexicon approach needs no training data and is fully explainable, but it misses sarcasm, slang and domain-specific meaning ("sick" as praise).

    Limitations. English only, small dictionary, no sarcasm detection. For production, compare against a labelled sample and consider a trained model such as a Hugging Face sentiment pipeline.
